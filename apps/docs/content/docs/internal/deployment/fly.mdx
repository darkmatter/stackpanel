Container-based deployment to [Fly.io](https://fly.io) with generated `fly.toml`.

The external [Fly module](https://github.com/darkmatter/stackpanel-registry/tree/main/modules/fly) declares its app options, actions, and Studio panels. The Cloud panel displays evaluated configuration without contacting Fly. A live status request runs the module's `status` action for the selected app; deployment is a separate confirmed action.

## Usage

```nix
stackpanel.apps.web.deployment = {
  enable = true;
  host = "fly";
  fly = {
    appName = "my-web-app";
    region = "iad";
    memory = "256mb";
    minMachines = 1;
  };
  container = { type = "bun"; port = 3000; };
};
```
