---
title: Module discovery and auto-import
description: How bundled, local, and external module definitions enter the project evaluation.
---

The flake adapter composes the Stackpanel schema with the consumer's explicit imports, local `.stack/modules/` and `.stack/nix/` directories, and the `stackpanelModules.default` outputs discovered on direct inputs. The bundled module loader imports non-private directories under `nix/stackpanel/modules/`; a leading dot or underscore marks a private directory.

All of these definitions register in `stackpanel.modules`. Studio reads `modulesListAll` for descriptors (including disabled modules) and `panelsList` for evaluated panels. Each panel names its owner; Studio mounts it only when the panel and its module are enabled.

See [Flake inputs and discovery](/docs/extensions/flake-inputs) for hooks and opt-out behavior and [Writing a module](/docs/extensions/writing-extensions) for the public SDK.
