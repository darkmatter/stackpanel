# stack project default

Set or show the default project.

The default project is used by the agent for v1 API requests that send no
X-Stackpanel-Project header, when the agent has no current project.

Without arguments, shows the current default project.
With a path argument, sets that project as the default.

Examples:
  stack project default              # Show default project
  stack project default .            # Set current directory as default
  stack project default ~/myproject  # Set specific project as default
  stack project default --clear      # Clear default project

## Usage

```bash
stack project default [path]
```


## Flags

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--clear` | `bool` | `false` | Clear the default project |
