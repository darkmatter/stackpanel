# Panels Options

## `panels`

UI panels for installed Stackpanel modules. Each panel declares an owning `module` and optionally a placement `slot`. Declare named widgets under `spec.widgets`; Studio infers the renderer. Built-in and external modules use the same panel catalog.

| Property | Value |
|----------|-------|
| **Type** | `attribute set of (submodule)` |
| **Default** | `{ }` |

**Example:**

```nix
{
  report-summary = {
    module = "report";
    title = "Workspace report";
    slot = "overview";
    spec.widgets.run.actions.ids = [ "report" ];
  };
}
```

## `panels.<name>.spec`

A native layout, mutually exclusive with `uiBundle`. [Named widgets](/docs/extensions/writing-extensions#author-a-panel-in-nix) use `spec.widgets.<id>.<kind>` with typed, documented fields from the Studio catalog. Use ordered child IDs on stacks and sections. `mkModule.ui` accepts the same layout for its module-detail panel. Tools can also supply a raw `{ root, elements, state? }` document or a tracked JSON file path.
