# Healthchecks Options

Runtime probes are declared under [`stackpanel.doctor.<module>.<name>`](/docs/reference/doctor)
with `scope = "runtime"`. This option group only controls the studio's
"System Health" panel, which is built from those checks. The
`healthchecksComputed` / `healthchecksList` outputs and their
`HEALTHCHECK_TYPE_*` wire strings are derived in `doctor.nix` and are unchanged.

## `healthchecks.enable`

Enable the healthcheck UI panel built from runtime-scope doctor checks.

| Property | Value |
|----------|-------|
| **Type** | `boolean` |
| **Default** | `true` |
