# Stackpanel Minimal Project

This project was generated from the Stackpanel minimal template.

## Getting Started

```bash
nix develop
# or, with direnv
direnv allow
```

## Configuration

Edit `.stack/config.nix` for Stackpanel options. Add custom packages or checks in `flake.nix` under `perSystem`.

## Common Commands

| Command | Description |
|---------|-------------|
| `nix develop` | Enter the development shell |
| `nix flake check` | Run flake checks |
