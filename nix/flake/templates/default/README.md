# Stackpanel Project

This project was generated from the Stackpanel default template.

## Getting Started

```bash
nix develop
# or, with direnv
direnv allow
```

## Configuration

Edit `.stack/config.nix` to configure packages, language toolchains, apps, services, IDE integration, and generated files.

## Common Commands

| Command | Description |
|---------|-------------|
| `nix develop` | Enter the development shell |
| `dev` | Start configured process-compose services after entering the shell |
| `stack status` | Show Stackpanel status |
| `stack commands` | List available commands |
